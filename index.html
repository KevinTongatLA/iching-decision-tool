决策时机工具 Decision-Timing Tool — Pilot: BaZi + Current Moment

Scope of this pilot: Four Pillars (八字) for a person, and the same engine applied to the current moment (环境/当下). No I-Ching hexagram/timing layer yet — that's the next step. This is a codified traditional heuristic system, not a validated predictive model.

命主 — Person

Uses local civil clock time as entered — no true-solar-time / longitude correction yet (a refinement for later; matters most near hour-pillar boundaries).

时辰推算 Birth-time rectification

Uses the date above (hour field ignored) plus your gender. Generates candidate hours, computes each one's 大运 (decade luck pillars), and scores how well each candidate's "structural turbulence" timeline (大运交接 / 冲日柱 / 冲大运 / 冲时柱-子女宫) lines up with ages you remember as major turning points — timing only, not event type. Note: Da Yun itself barely changes between candidate hours on the same day (it's keyed to the month pillar) — most of the discrimination between candidates comes from the Hour pillar's own clashes, so this works best with a few ages spread across your life, not just one. This is a best-fit heuristic, not a certainty.

时刻 — Moment (default: now)

Pick any date/time to see its Four Pillars, and — once you've computed the person above — how that moment compares to them.

环境周期 — Environment Cycle EXPERIMENTAL — not classical I-Ching

Set this first — it's not experimental (it drives 用神 selection for the hexagram below), but it should also frame which environment scopes make sense to describe. A wealth/investment decision calls for a market-related scope; a career decision calls for a job-market or industry one — not the other way around.

Below this is a reasoned extension, not something in the classical texts: it applies the tradition's own method of reading cycles through Wu Xing (used classically for dynastic succession, 五德终始说, and for the body in Chinese medicine) to a real-world cycle you describe — a market, an industry, a project's funding climate, anything with a recognizable cycle shape. Off by default — with it off, the rest of the tool behaves exactly as before. You judge the phase; the tool only translates it into the same Five-Element language the rest of the engine already speaks.

Add one row per scope you want to check — a big-picture cycle and a narrower one within it can be in different phases at the same time (e.g. the overall market expanding while one industry inside it is late-stage contracting). Each row is read independently, never averaged together.

起卦 — Cast a Hexagram for this Moment

Deterministic 梅花易数 time-based casting (年月日时起卦法) from the Moment panel's date/time above — no randomness. Lunar month/day are computed using China Standard Time civil dates regardless of the Moment panel's timezone field, matching classical practice. If the person's Four Pillars are computed, each line is also checked against their Day Master and day branch. 决定类型 (which line becomes 用神) is set in the Environment panel above.

寻找更好时机 — Scan for a better time

Requires the person's Four Pillars computed above. Scans forward from the Moment panel's current date/time and ranks candidates by the composite score below (see the "关于评分" note under the results) — a starting point for comparison, not a verdict.

校验 — Day-pillar offset: confirmed

Cross-checked against an online 黄历 for two dates 8 days apart (2026-08-24 → 庚午, 2026-09-01 → 戊寅) — both matched this tool's output, so GANZHI_JD_OFFSET = 49 is correct. Since day-pillar computation is just a continuous day count (not tied to those specific dates), this confidence extends to other dates too. The manual override below is kept as a fallback only.
